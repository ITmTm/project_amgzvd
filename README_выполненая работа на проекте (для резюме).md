## Что построено за время редизайна (новые страницы и блоки)

Ниже — разделы, которые были спроектированы и свёрстаны с нуля в рамках текущего редизайна (не унаследованы от старого шаблона). Для каждого — где лежит, что хранит папка и как устроена реализация.

### `office/` — Контакты
*Май–июнь 2026*

Хранит: `index.php` (три блока: баннер с city-selector, список офисов/складов, карта), `css/style.css`, `img/`.

Реализация:
- Баннер использует существующий глобальный триггер `data-city-show` для переключения города.
- Список контактов группирует офисы и склады раздельно, с карточками дилеров и контактами отделов.
- Карта и форма — через модифицированный `local/components/amega/form` с новым параметром `MAP => true` в `template.php`: вместо фото рендерится div с Яндекс.Картой. Параметр сделан переиспользуемым для других страниц.
- Скрипт карты остаётся инлайном в `index.php` (не вынесен в отдельный `.js`), т.к. использует PHP-данные `$OFFICES_LIST` на этапе рендера.
- Кастомные SVG-маркеры на карте вместо стандартного `islands#circleIcon`, размер `[35, 35]`, offset `[-16, -20]`.
- Вся старая PHP-логика сохранена: `$DILER_LIST` (инфоблок 55), `$OFFICES_LIST` (инфоблок 51), исключения городов `nnovgorod`/`ulyanovsk`, условный телефон для города `244735`.

### `moskitnyye-setki/` — Москитные сетки
*Июнь 2026*

Хранит: `index.php`, `css/`, `js/` (4 файла — компактная страница).

Реализация:
- Двухуровневая sticky-навигационная панель: `position: sticky; top: 143px` — проблема со «съезжающим» sticky была не в CSS-позиционировании, а в лишнем `margin-bottom` на `.mosquito-sticky`, схлопывающем высоту родителя.
- Каталог рендерится через JS из статичных объектов `montageData` (4 таба монтажа) и `polotnoData` (6 табов полотна) — без обращения к инфоблокам.
- Фотослайдер на Swiper с `destroy()`/переинициализацией при переключении таба (иначе слайдер «залипает» на старых слайдах).
- Кастомный чекбокс сравнения с SVG-маркером — тот же паттерн, что и в `window-lineup/profiles/`.
- Страница добавлена в шапку сайта как новая ветка меню между «Окна» и «Балконы».

### `windows/okna-s-laminatsiyey/` — Окна с ламинацией (блок `lam-colors`)
*Июнь–июль 2026, в активной разработке*

Хранит: `index.php`, `css/style.css`, `js/script.js`.

Реализация (таблица сравнения 42 цветов × до 10 колонок профилей):
- JS-рендер `tbody` с хелпером `colorHasMatch()` и функцией `getVisibleProfiles()` для фильтрации по табам глубины профиля + выпадающим спискам цвета/срока.
- Пустая строка состояния при отсутствии совпадений; невидимые строки полностью удаляются из DOM, а не скрываются через `display: none`.
- Sticky-заголовок реализован через клонированный `thead`, добавленный в `body` на `position: fixed; top: 142px`, с двухрядной структурой (`.h-top` + `.h-main`); ширина колонок синхронизируется через `outerWidth()`, горизонтальный скролл синхронизирован между клоном и оригиналом.
- Тултип на `position: fixed` с пересчётом позиции для мобильных (`≤ 768px`).
- `profileDisplayNames` — карта переопределения отображаемых названий профилей.
- Точечные фиксы: `clearTimeout()` перед новым `setTimeout()` при быстром переключении табов (гонка состояний), regex `/\n/g` для переносов строк в тултипе, `Array.from()` вместо `Array.fill()` (некорректно создавал общие ссылки на объект), `visibility: hidden` на обёртке таблицы с раскрытием через JS (убирает мигание границ при первом рендере), синхронизация `opacity` между `thead` и `tbody` при переключении таба.

### `local/components/amega/configurator/` — Интерактивный конфигуратор окон

Хранит: `class.php` (`CAmegaConfiguratorComponent`), шаблон `windows/` (`template.php`, `script.js`, `style.css`).

Реализация (последние итерации, v2.2):

- Поля `cfg_count` (количество конструкций) и `cfg_address` (адрес монтажа) — показываются только для физлиц, `disabled` для юрлиц, маппятся в CRM (`UF_CRM_1667311679049`, `UF_CRM_1667311761516`).
- CRM-маппинг полей `UF_CRM_1778154022`–`UF_CRM_1778154603` и UTM-трекинг (`UTM_SOURCE` и т.д.) добавлены во все скрипт-файлы конфигуратора.
- Спиннер загрузки страницы (`#page-loader`) добавлен в шаблоны.
- Слайдер параметров на Swiper с CSS grid override на десктопном брейкпоинте.
- Изначально жил в `/parts/configurator/`, затем оформлен как полноценный Bitrix-компонент `amega:configurator` — этот архив уже отражает новую архитектуру.

### Email-подпись и шаблон рассылки
*Июнь 2026*

Хранит: `email/27/` (SVG-ассеты: лого, футер, шапка филиала).

Реализация: HTML-подпись и Stripo-шаблон для маркетолога. Ключевая проблема — изображения с Яндекс.Диска не грузятся в почтовых клиентах; решение — публичные ссылки Битрикс24 (`bitrix24public.com/...showFile?token=...`), полученные через контекстное меню картинки на публичной странице шаринга. Подпись включает лого, соцсети (МАКС, Telegram, ВКонтакте) и ссылки на бот-ассистента. В футере шаблона рассылки соцсети заменены тремя QR-кодами.
